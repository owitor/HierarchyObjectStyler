# Hierarchy Styler Pro

## How to Use (English)

1. Select any GameObject in your scene.
2. Click **Add Component** and add **Hierarchy Object Styler**.
3. Customize the available options in the Inspector:
   - Background color
   - Text color
   - Font style and size
   - Text alignment
   - Text case (Original / Uppercase / Lowercase)
   - Icon type, size, and spacing
4. Changes are applied instantly in the Unity Hierarchy window.

This tool is Editor-only and has no runtime impact.

## Como Usar (Português)

1. Selecione qualquer GameObject na cena.
2. Clique em **Add Component** e adicione **Hierarchy Object Styler**.
3. Configure as opções disponíveis no Inspector:
   - Cor de fundo
   - Cor do texto
   - Estilo e tamanho da fonte
   - Alinhamento do texto
   - Capitalização do texto (Original / Maiúsculo / Minúsculo)
   - Tipo de ícone, tamanho e espaçamento
4. As mudanças aparecem instantaneamente na Hierarchy da Unity.

Esta ferramenta funciona apenas no Editor e não afeta o runtime.

## Notes

- Works with Unity 2021.3+ (Unity 6 compatible)
- No setup required
- Lightweight and performance-friendly
